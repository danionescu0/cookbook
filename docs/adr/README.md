# Architecture Decision Records

This folder holds Architecture Decision Records (ADRs) for the cookbook project, using the
[MADR 4.0](https://adr.github.io/madr/) template. Each record captures a single significant
decision — its context, the options considered, and the consequences — so future contributors
can understand *why* the code looks the way it does, not just what it does.

New ADRs are numbered sequentially (`NNNN-title-in-kebab-case.md`) and are never renumbered or
deleted once merged; a superseded decision gets a new record that says so and links back.
